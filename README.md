# Diwali_Sales_Dashboard-Using-Power-BI
Developed an interactive Power BI Diwali Sales Dashboard to analyze customer demographics, regional sales trends, product category performance, occupation-based spending patterns, and state-wise revenue contributions using KPI cards, slicers, treemaps, donut charts, and bar charts.

# Key Highlights

📈 Strong Overall Sales Performance.

👩 Female Customers Drive Sales.

👨‍👩‍👧‍👦 Age Group 26–35 is the Most Valuable.

💼 IT Professionals are the Top Buyers.

🛍️ Product Category Demand is Concentrated.

💍 Marital Status Insights.

🌎 Regional Analysis Available.
